# 多模型与媒体能力验收

验收日期：2026-11-01。

## 实现范围

- 自定义模型目录管理生成、意图、ASR、TTS，支持 OpenAI 兼容接口、SystemOne，以及火山 Agent Plan 原生语音协议。没有厂商模板或在线模型列表。
- 模型必须真实测试成功才能保存，验证结果绑定配置版本；旧模型需要重新测试。首次通过测试的生成模型自动成为全局默认。
- 每项模型在右侧抽屉独立编辑，支持输入／输出预算、图片和工具能力、思考参数及多个自定义 HTTP 请求头；Agent Plan TTS 提供官方 2.0 音色选择。
- Token、请求头值和 B 站 Cookie 加密保存，管理接口不回显秘密值。密钥首次使用创建并设置为 `0600`；备份必须同时包含数据库和持久化密钥文件。
- 复用 `system_settings.payload`，不新增 Ent 表或数据库迁移；维持现有数据库部署流程。
- 生成模型按“会话指定 → 对应账号好友／群模板 → 全局默认”解析。整次运行固定模型快照，客户端按版本缓存，被引用模型禁止删除。
- 意图行为设置位于“意图识别／识别配置”。生成能力由已验证模型推导；语音识别和合成语音分别授权，并在执行时检查权限及模型依赖。
- 图片和工具返回画面作为真实图片内容进入模型请求，历史读取遵守授权；读取失败和文本模型均有明确标记。
- QQ 语音在意图判断前转写，成功结果持久化复用，并移除原始语音下载元数据；失败不绕过会话参与规则。
- 视频工具 `dsh-video-vision` 支持 QQ 附件、B 站链接／BV／短链接／分 P，返回带时间戳画面及字幕，获授权且 ASR 可用时转写缺失字幕的音轨。默认 6 帧、最多 12 帧，下载上限 512 MiB，缓存 24 小时；不接受用户提供的服务器文件路径。
- TTS 使用当前会话发送工具、预算和投递台账；成功后避免重复文字回复，未知投递不自动重发。
- Langfuse 敏感运行保留脱敏的模型与工具记录，隐藏图片、凭证及原始错误详情；应用仍记录决策与运行步骤。
